# fanzai.heart网站API文档

## 和我沟通时，请遵守以下准则

1. **不要频繁打断我**。我做事需要进入心流状态，两分钟打断一次就没法集中了，最好等我空闲了再来找我。
2. **讨论尽量在办公室之外进行**，去走廊、会议室或外面。办公室需要安静的工作环境，不是办事大厅。
3. **讨论前先自己准备好**。讨论的前提是双方都对这个话题有自己的想法、读过相关资料，**本质是信息交换**。不读文章就光聊是没用的，没墨水的笔划不出字。
4. **实事求是，就事论事**。讨论时以事实为准，不要为了说服对方而夸大或歪曲。情绪上来了就别讨论了，冷静下来再说。
5. **不要让别人为不是我造成的问题负责**。我不是什么项目的 leader，也别让我承担外交责任。
6. **帮我干活之前想清楚，不想参与就别拖拖拉拉**。如果一开始就不想参与，就不要去参与，拖着反而更麻烦。
7. **我如果需要什么，会直接说**，不用猜。也别不好意思提需求。
8. **不要老让我负责杂活**。我负不了一点额外的责任，把自己的事干好就不错了。
9. **不要传递过多负能量**。负能量在一个圈子内部越积越重不好，也不要老集中在同一个人身上释放。
10. **帮我了至少得说声谢谢**，而且要真心，别流于形式。喊"大佬"可能反而让人觉得是嘲讽。
11. **如果让我感到不舒服，可以直接说出来**。大家都不是坏人，把问题说开就好受点。
12. **对于老师一定要尊重**，不管我私下怎么吐槽。
13. **不要把负面情绪映射为"我不行"**。工作压力和事情本身是两回事，不要因此否定自己。
14. **做事有明确的边界**。个人有核心利益不容侵犯，只要对方不是完全不讲理就没事。真正的核心利益其实不多。
