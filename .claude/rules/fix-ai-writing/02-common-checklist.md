# 常见问题修复清单

## 空洞大词替换表
- 赋能 → 具体动词（帮助/提升/改进）
- 重塑 → 改进/优化/调整
- 颠覆 → 改变/革新
- 新范式 → 新方法/新思路
- 革命/突破 → 重要进展/显著改进
- 深度融合 → 结合/整合
- 闭环 → 完整流程
- 多维度 → 多方面/不同角度

## 套话连接词删除
- 删除：首先、其次、再次、最后
- 删除：值得注意的是、值得关注的是
- 删除：进而、从而（除非逻辑必要）
- 删除：切实推动、有效赋能、大力推进

## 修辞泛滥处理
- 排比句只保留一个
- 比喻句全文只用1-2处
- 删除"不是……而是……"的重复

## 标点符号调整
- 破折号（——）改逗号或分两句
- 冒号+分号改句号+逗号
- 括号内容改正文或删除
- 引号只用于术语和引用

## 句子节奏优化
- 长句（30+字）拆成2-3短句
- 短句（10-15字）合并成长句
- 避免3个以上连续相似长度句子

## 翻译腔+公文腔修正
- "在某种意义上说" → 删除或改"某种程度上"
- "切实推动" → 推进/促进
- "有效赋能" → 帮助/支持
- "话语建构" → 理论框架/研究体系

## 逻辑推进检查
- 每段首句不要重复
- 删除总结+套话的过渡句
- 确保每段有新信息

## 证据具体化
- "大量研究" → 引用具体研究
- "实践证明" → 删除或举例
- 删除编造的引文和数据

## 添加真人感
- 加入"我认为""可能""或许"
- 加入具体细节和例子
- 加入个人语气和观点
